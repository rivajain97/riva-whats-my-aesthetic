# Favorite outfits

Drop your 10–15 real favorite-outfit photos directly in this folder. Any
filenames are fine (e.g. `outfit_01.jpg`, `date_night.jpg`), and any common
image format works (JPG, PNG, HEIC).

These photos are **not** the wardrobe inventory (see `data/wardrobe.json`).
They're examples the agent analyzes — with the `analyze-outfit-aesthetic`
Skill — to find recurring aesthetic patterns (color palette, contrast,
silhouette, accessories, etc.) across outfits you already love. The agent
discovers whatever images are in this folder at runtime, so nothing else
needs to be updated when you add or remove a photo.

No outfits are invented or described here — this README intentionally
contains no guesses about what the photos look like.
